## 0. 개요

QLINK 앱의 첫 인상과 핵심 가치 전달을 담당하는 3개 화면군을 정의한다.

| 구분 | 화면 ID | 노출 시점 | 목적 |
|---|---|---|---|
| 스플래시 | #M-SPLASH | 앱 실행 시 매번 | 브랜드 각인 + 로딩 커버 |
| 온보딩 | #M-ONBOARDING | 최초 설치 후 1회 | 핵심 가치 3가지 전달 + 가입 유도 |
| 튜토리얼 | #M-TUTORIAL | 가입 직후 1회 (+ 설정에서 재열람) | 주요 기능 사용법 안내 |

공통: non-shell (Header/TabBar 숨김), 세로 전용, 360~480px viewport 기준.

## 1. 스플래시 (#M-SPLASH)

### 1.1 진입 조건

| 조건 | 동작 |
|---|---|
| 앱 실행 (cold start) | 스플래시 1.5~2초 표시 후 분기 |
| 이미 로그인 | 스플래시 → #M-HOME |
| 미로그인 + 온보딩 미완료 | 스플래시 → #M-ONBOARDING |
| 미로그인 + 온보딩 완료 | 스플래시 → #M-AUTH-LOGIN |

### 1.2 화면 구성

```
┌─────────────────────────────┐
│                             │
│                             │
│         (중앙 정렬)          │
│                             │
│      [QLINK 로고 아이콘]     │  48x48, 그라디언트
│          QLINK              │  28px, bold, gradient text
│                             │
│   "링크를 행동으로 바꾸다"    │  14px, text-muted
│                             │
│                             │
│       [로딩 인디케이터]       │  gradient dot pulse (3개)
│                             │
│                             │
│     ver 1.0                 │  12px, text-muted, 하단 고정
└─────────────────────────────┘
```

### 1.3 애니메이션 시퀀스

| 시간 | 요소 | 애니메이션 |
|---|---|---|
| 0~300ms | 배경 | `--qlink-bg` fade-in |
| 200~600ms | 로고 아이콘 | scale(0.8→1) + opacity(0→1), ease-out |
| 400~800ms | "QLINK" 텍스트 | opacity(0→1) + translateY(8→0), ease-out |
| 600~1000ms | 태그라인 | opacity(0→1), ease-out |
| 800~1500ms | 로딩 도트 | 3개 dot가 순서대로 pulse (loop) |
| 1500~2000ms | 전체 | opacity(1→0), 다음 화면 전환 |

### 1.4 디자인 사양

- 배경: `var(--qlink-bg)` (테마 연동)
- 로고 텍스트: `var(--grad-primary)` gradient, font-weight 800
- 태그라인: `var(--qlink-text-muted)`, font-weight 400
- 로딩 도트: `var(--qlink-primary)` 기반, 6px 원, gap 8px
- 전환: crossfade 300ms

### 1.5 기술 참고

- `localStorage.getItem('qlink-onboarding-done')` 으로 온보딩 완료 여부 판별
- 스플래시 중 zustand persist rehydration 완료 대기
- PWA manifest `background_color`와 스플래시 배경색 통일

## 2. 온보딩 (#M-ONBOARDING)

### 2.1 진입 조건

- 최초 설치 후 1회만 노출
- 스플래시 → 미로그인 + 온보딩 미완료 시 자동 진입
- 완료 시 `localStorage.setItem('qlink-onboarding-done', 'true')`

### 2.2 구조: 3장 슬라이드 (스와이프)

전체 레이아웃:
```
┌─────────────────────────────┐
│  [건너뛰기]          (우상단) │  14px, ghost button
│                             │
│                             │
│      [일러스트/아이콘]       │  160x160 영역, 중앙
│                             │
│      [헤드라인]              │  20px, bold, 중앙
│      [설명 텍스트]           │  14px, muted, 중앙, 2줄
│                             │
│                             │
│      ● ○ ○                 │  페이지 인디케이터
│                             │
│  [다음] 또는 [시작하기]       │  btn-primary, full-width
│                             │
└─────────────────────────────┘
```

### 2.3 슬라이드별 콘텐츠

#### 슬라이드 1 — 흩어진 즐겨찾기 통합 (페인포인트)

| 항목 | 내용 |
|---|---|
| 일러스트 | Safari, Chrome, 네이버앱, PC 브라우저 아이콘 4개가 각각 따로 놀고 있는 모습. 가운데 QLINK 로고로 화살표가 모이는 구성 |
| 헤드라인 | **"즐겨찾기, 여기저기 흩어져 있죠?"** |
| 설명 | Safari, Chrome, 네이버앱, 회사 PC, 집 PC. 브라우저마다, 기기마다 따로 노는 즐겨찾기. QLINK 하나면 전부 한곳에. |
| 강조 색상 | `var(--qlink-primary)` |

#### 슬라이드 2 — AI 자동 정리

| 항목 | 내용 |
|---|---|
| 일러스트 | 링크 카드 + AI 스파클 + 폴더 자동 분류 아이콘 조합 |
| 헤드라인 | **"저장하면 AI가 알아서"** |
| 설명 | 1초 저장, 한 줄 요약, 태그, 폴더 분류까지 자동으로 끝. |
| 강조 색상 | `var(--qlink-primary-2)` |

#### 슬라이드 3 — 할 일 + 알림 + CTA

| 항목 | 내용 |
|---|---|
| 일러스트 | 체크리스트 + 알림 벨 아이콘 조합 |
| 헤드라인 | **"저장만? 행동까지."** |
| 설명 | 링크마다 할 일과 반복 알림을 달면 절대 놓치지 않아요. |
| 강조 색상 | `var(--qlink-accent)` |
| CTA 버튼 | "시작하기" → #M-AUTH-LOGIN 이동 |

### 2.4 인터랙션 사양

| 항목 | 동작 |
|---|---|
| 스와이프 | 좌우 스와이프로 슬라이드 전환 (touch + mouse drag) |
| 인디케이터 | 현재 슬라이드 = filled dot (`var(--qlink-primary)`), 나머지 = outlined |
| "다음" 버튼 | 슬라이드 1~2에서 노출. 탭 시 다음 슬라이드 |
| "시작하기" 버튼 | 슬라이드 3에서만 노출. 탭 시 온보딩 완료 처리 + 로그인 이동 |
| "건너뛰기" | 슬라이드 1~2에서 우상단. 탭 시 온보딩 완료 처리 + 로그인 이동 |
| 전환 애니메이션 | translateX slide + opacity, 300ms ease-out |
| 자동 넘김 | 없음 (사용자가 직접 넘기도록) |

### 2.5 디자인 사양

- 배경: `var(--qlink-bg)` 위에 각 슬라이드별 `var(--grad-soft)` 일러스트 배경 원
- 텍스트: 헤드라인 `var(--qlink-text)`, 설명 `var(--qlink-text-muted)`
- 버튼: `btn-primary` (그라디언트 배경)
- "건너뛰기": `var(--qlink-text-muted)`, 밑줄 없음, 14px
- 인디케이터 dot: 8px, gap 8px, 활성 = primary, 비활성 = border color
- 일러스트 영역: 160x160px, `var(--qlink-surface)` 원형 배경 위에 이모지/아이콘

## 3. 튜토리얼 (#M-TUTORIAL)

### 3.1 진입 조건

| 조건 | 동작 |
|---|---|
| 가입 완료 직후 (첫 로그인) | 자동 진입 (1회) |
| 설정 > "사용법 다시 보기" | 수동 재진입 가능 |
| 완료 시 | `localStorage.setItem('qlink-tutorial-done', 'true')` |

### 3.2 형식: 코치마크 (Tooltip Overlay) 5단계

> 실제 홈 화면 위에 반투명 오버레이를 깔고, 단계별로 UI 요소를 하이라이트하며 말풍선으로 설명하는 방식.

전체 레이아웃:
```
┌─────────────────────────────┐
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │  반투명 오버레이
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │  (rgba(0,0,0,0.6))
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
│  ▓▓▓┌────────────────┐▓▓▓▓ │
│  ▓▓▓│  하이라이트 영역  │▓▓▓▓ │  해당 UI 요소만 밝게
│  ▓▓▓└────────────────┘▓▓▓▓ │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
│  ┌─────────────────────┐   │
│  │ 💡 설명 텍스트       │   │  말풍선 tooltip
│  │    (1/5) [다음]      │   │
│  └─────────────────────┘   │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
└─────────────────────────────┘
```

### 3.3 단계별 콘텐츠

#### Step 1 — FAB (링크 추가)

| 항목 | 내용 |
|---|---|
| 하이라이트 대상 | FAB 버튼 (우하단) |
| 말풍선 위치 | FAB 좌상단 |
| 말풍선 내용 | **"여기서 링크를 추가해요"** 짧게 누르면 바로 추가, 길게 누르면 QR 스캔도 가능해요. |
| 인디케이터 | 1/5 |

#### Step 2 — 홈 링크 카드

| 항목 | 내용 |
|---|---|
| 하이라이트 대상 | 홈 화면의 샘플 링크 카드 1개 (시드 데이터) |
| 말풍선 위치 | 카드 하단 |
| 말풍선 내용 | **"AI가 자동으로 요약해요"** 저장하면 한 줄 요약, 태그, 폴더 분류가 자동 완성돼요. |
| 인디케이터 | 2/5 |

#### Step 3 — 폴더 탭

| 항목 | 내용 |
|---|---|
| 하이라이트 대상 | 하단 탭바의 "폴더" 아이콘 |
| 말풍선 위치 | 탭바 상단 |
| 말풍선 내용 | **"폴더로 깔끔하게"** AI가 자동 분류하고, 직접 폴더를 만들어 정리할 수도 있어요. |
| 인디케이터 | 3/5 |

#### Step 4 — 할일 탭

| 항목 | 내용 |
|---|---|
| 하이라이트 대상 | 하단 탭바의 "할일" 아이콘 |
| 말풍선 위치 | 탭바 상단 |
| 말풍선 내용 | **"링크에 할 일을 달아요"** 1회 알림, 반복 알림까지. 저장만 하고 잊어버리는 일은 이제 끝. |
| 인디케이터 | 4/5 |

#### Step 5 — 검색

| 항목 | 내용 |
|---|---|
| 하이라이트 대상 | 헤더 우측 검색 아이콘 (🔍) |
| 말풍선 위치 | 아이콘 하단 |
| 말풍선 내용 | **"요약 내용도 검색돼요"** 제목뿐 아니라 AI 요약, 태그, 메모까지 한 번에 찾을 수 있어요. |
| 인디케이터 | 5/5 |
| CTA | "시작하기" 버튼 → 튜토리얼 완료, 홈 진입 |

### 3.4 인터랙션 사양

| 항목 | 동작 |
|---|---|
| 오버레이 탭 | 아무 곳 탭 → 다음 단계 (말풍선 밖 영역) |
| "다음" 버튼 | 다음 단계로 이동 |
| "건너뛰기" | 우상단 텍스트 버튼, 탭 시 튜토리얼 즉시 완료 |
| 전환 | 현재 말풍선 fade-out(200ms) → 하이라이트 이동(300ms) → 새 말풍선 fade-in(200ms) |
| 마지막 단계 | "다음" 대신 "시작하기" 버튼 (btn-primary 스타일) |
| 뒤로가기 | 이전 단계로 (물리 백 버튼 / 스와이프 백) |

### 3.5 시드 데이터 (튜토리얼용)

> 가입 직후 빈 화면이면 코치마크가 의미 없으므로, 튜토리얼 진입 시 샘플 데이터 3개를 임시 주입한다.

| 샘플 링크 | 폴더 | 요약 |
|---|---|---|
| https://example.com/ai-trends | 기술 💻 | "2026년 AI 트렌드 TOP 10 정리" |
| https://example.com/cafe-review | 카페 투어 ☕ | "성수동 신상 카페 3곳 리뷰" |
| https://example.com/job-posting | 미분류 📥 | "네이버 PM 채용 공고 (6/30 마감)" |

튜토리얼 완료 시 사용자 선택:
- "샘플 유지하기" → 샘플 데이터 유지
- "깨끗하게 시작" → 샘플 데이터 삭제

### 3.6 디자인 사양

- 오버레이: `rgba(0, 0, 0, 0.6)`, 하이라이트 영역은 `border-radius: var(--r-md)` + `box-shadow: 0 0 0 4px var(--qlink-primary)`
- 말풍선: `var(--qlink-surface)` 배경, `var(--r-md)` radius, `var(--shadow-md)` 그림자
- 말풍선 텍스트: 제목 16px bold `var(--qlink-text)`, 설명 13px `var(--qlink-text-muted)`
- 인디케이터: "1/5" 형태, 13px, `var(--qlink-text-muted)`
- "다음"/"시작하기": 말풍선 내 우하단, 14px, `var(--qlink-primary)` 텍스트 버튼 (마지막만 btn-primary)
- "건너뛰기": 화면 우상단 고정, 14px ghost

## 4. 전체 흐름도

```
[앱 실행]
    │
    ▼
#M-SPLASH (1.5~2초)
    │
    ├─ 로그인 O ──────────────────────────► #M-HOME
    │
    ├─ 로그인 X + 온보딩 완료 ──────────► #M-AUTH-LOGIN
    │
    └─ 로그인 X + 온보딩 미완료
         │
         ▼
    #M-ONBOARDING (4장 슬라이드)
         │
         ├─ "시작하기" / "건너뛰기"
         │
         ▼
    #M-AUTH-LOGIN
         │
         ├─ 가입 완료 (첫 로그인)
         │      │
         │      ▼
         │  #M-TUTORIAL (코치마크 5단계)
         │      │
         │      └─ 완료 → #M-HOME
         │
         └─ 기존 회원 로그인 → #M-HOME
```
